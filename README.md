# Спортік — трекер тренувань (PWA)
Статичний сайт без збірки. Дизайн — Material 3 Expressive (шрифти Roboto Flex і Material Symbols з Google Fonts; без них працює із системним шрифтом та емодзі). Дані в localStorage (ключ `sportik.v1`), бекап — Програма → Експорт/Імпорт JSON.
Локально: `python3 -m http.server 8000` → http://localhost:8000. Хостинг: будь-який статичний (GitHub Pages, HF static Space) — просто скопіювати файли.
Після змін у файлах збільште `CACHE` у service-worker.js.
