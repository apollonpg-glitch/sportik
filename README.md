# Спортік — трекер тренувань (PWA)
Статичний сайт без збірки й без зовнішніх залежностей. Дані в localStorage (ключ `sportik.v1`), бекап — Програма → Експорт/Імпорт JSON.
Локально: `python3 -m http.server 8000` → http://localhost:8000. Хостинг: будь-який статичний (GitHub Pages, HF static Space) — просто скопіювати файли.
Після змін у файлах збільште `CACHE` у service-worker.js.
